# Урхины Ертөнц (game/)

Платформер тоглоом + онооны самбар. Нүүр хуудасны `#game` хэсгээс `game/` руу холбогдоно.

## Онооны самбар
- Тоглогч нэрээ бичиж эхэлнэ. Түвшин ахихад болон дуусгахад `{name, level, deaths, done}` илгээгдэнэ.
- Эрэмбэ: бүгдийг давсан > өндөр түвшин > цөөн амь зарцуулсан. Нэг нэр нэг мөр (хамгийн сайн нь үлдэнэ).
- Эхний 3 нь цом, 4-10 нь тоон жагсаалт.

## Дундын самбар идэвхжүүлэх (нэг удаа)
1. Cloudflare → Workers & Pages → KV → Create namespace (жишээ нь `jaybee-scores`).
2. Өөрийн Worker (`jaybee`) → Settings → Bindings → Add → KV namespace → Variable name: `SCORES`.
3. `worker/telegram-worker.js`-ийн шинэ кодыг Worker руу хуулж Deploy хийнэ.

KV холбоогүй үед самбар зөвхөн тухайн төхөөрөмж дээр (localStorage) хадгалагдана, тоглоом хэвийн ажиллана.
